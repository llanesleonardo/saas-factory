# Agent definitions (markdown roles)

Canonical **role markdown** for SaaS Factory agents lives here. **`factory/02_workforce/02_00_agents/agent-registry.json`** points each **`agents.<id>.file`** at these paths; **`../context-packs/<id>.json`** supplies Cursor path hints.

TypeScript stubs under **`../agent-definitions/`** (legacy naming) are optional orchestration helpers — not the same as these markdown roles.
